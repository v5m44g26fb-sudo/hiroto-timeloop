調査日: 2026-11-09。対象: 『現役アイドル、Tinderやってた件』 `~/workspace/hiroto-tinder/`（現行 build v455、単一 `index.html` 約1.5MB／15,736行＋ `assets/` 262ファイル約26MB、フレームワークなし）。

## 2. 流用できないもの（作り替え）

- **Tinderアプリ本体**: 本作に出会い系・マッチング要素はない。丸ごと削除し、代わりに「番組アプリ」（名簿・順位・投票・ミッション表示、下記 §4）が本作の中心アプリになる
- 物語データ全般（会話文、記事、投稿、エンディング分岐、炎上編の文面など）
- 彼の写真セット: Tinder版は現行の私服・IG用が中心。過去編は各サバイバル編リポジトリの時代別公式プロフィールを使う（詳細: `ASSETS_NAO.md` §4）
- UIスキン: Tinder版は2026年現行仕様。本作は時代別スキンが必須（§3）

## 3. 時代別UIスキン差し替え（必須の新規作業）

| 時代 | チャット | SNS | その他 |
|---|---|---|---|
| 2019（日本・日プ編） | LINE（当時の緑基調・旧UI寄せ） | Twitter（旧ロゴ・旧UI）、Instagram（当時UI） | 番組公式サイト／投票UIは2019年当時の空気。スマホOSも当時世代の見た目に寄せる |
| 2021（中国・創造営編） | WeChat風チャット（新規スキン）＋日本側との連絡はLINE（時差・制限の演出） | Weibo風（新規スキン）。Instagram等は現地では使いにくい前提の演出 | 中国語UIの混在、現地配信・投票アプリ風スキン |
| 2023（韓国・ボイプラ編） | カカオトーク風（新規スキン） | Twitter（放送は2023年2〜4月。X改称前なのでTwitter表記が正）、Instagram（2023 UI） | Mnet系の投票・番組アプリ風スキン |
| 2026（現在編） | LINE現行 | X・Instagram現行（Tinder版スキンをそのまま使える唯一の時代） | Tinder版の現行ホーム／ロック画面がそのまま活きる |

- スキンは「時代ごとに配色＋アイコン＋呼称を差し替える」設計にし、アプリの挙動（§1）は共通エンジンで持つ
- 時代が進むごとにUIが新しくなること自体が、説明なしで時間経過を伝える装置になる（レポート要素12/14）

## 4. 新規開発が必要なもの

1. **番組アプリ**: 練習生名簿（時代別キャスト写真と連動）、自分の順位表示、ミッション／課題表示、投票画面（公式ルール内の投票のみ。複数アカウント等の不正投票は仕組みに入れない）
2. **ループ管理**: 周回カウンタ、時代×周回の進行管理、ループ開始時の「前回の30秒まとめ」自動生成
3. **差分再演エンジン**: 同一場面の再演時に同一文をグレー表示し、差分行だけハイライトする描画＋「Diff Log」（差分コレクション画面）
4. **応援台帳**: 前の周で成立した応援・救済が次の周の維持義務になるリスト管理（時代ごとに上限2〜3件、2周目は彼と共同維持）
5. **Keepsake Box**: 周を跨いで残る物・言葉の所持品管理（残るかどうかは「彼が残すと決めたもの」だけ、というルール付き）
6. **Canon Lock 結果画面**: 順位発表で「結果は固定／変わったのは中身」の内訳を表示する専用画面
7. **ゲージ基盤**: 違和感／男装バレ度／届いた数／主人公スキル（歌・ダンス）の継承計算（詳細は `DESIGN.md` §5）
8. **0周目リードオンリーモード**: 操作ボタンを持たない放送視聴パートの表示モード

## 5. リポジトリ構成の前提（v1着手時）

- `~/workspace/hiroto-timeloop/` に単一 `index.html` ＋ `assets/` で新規構築し、GitHub Pages 公開は既存作品と同じ運用（公開リポジトリ、版が上がるごとにプレイ用URLを共有）
- 土台コードは Tinder版 `index.html` を複製して物語データを差し替える方式が最速（元作→Tinder版の分岐時と同じ手順）
